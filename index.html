01

Add your report

In SmartView, export your report as a Basic Word document (.docx).

Which file do I need?

In SmartView Classic, choose the Basic report template and export to Word (.docx). Include one image record per page, with the thermal image, regular photo, image details and both original marker tables.

Export the image records without separate cover, contents, summary or histogram pages. This app uses the blend already saved in the export.

PDF, IS2 and maintenance Excel files aren’t supported here. Extra source notes are kept; longer tables or notes continue onto another page.
